## Capacidades transversales

- [ ] MDA CIM/PIM/PSM y trazabilidad PIM → PSM/navegación inversa.
- [ ] Invitación válida, vencida, agotada, revocada y roles owner/editor/viewer.
- [ ] Dos clientes online convergen y una operación duplicada no se aplica dos veces.
- [ ] Presencia, pérdida de conexión y recuperación de operaciones.
- [ ] Proyecto preparado offline, edición local, cierre/reapertura y reconciliación.
- [ ] Perfil OMG XMI 2.5.1: exportación, importación, cancelación y rollback.
- [ ] Perfil Sparx XMI 2.1: web → EA → web y pérdidas documentadas.
- [ ] IA: propuesta, diferencias, aceptación parcial, cancelación, permisos y fallo del proveedor.
